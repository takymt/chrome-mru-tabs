# chrome-mru-tabs

[Japanese](docs/README.ja.md)

A Chrome extension that switches back to the previously active tab.

## Development

```sh
nix develop
just setup
```

| Command      | Description                          |
| ------------ | ------------------------------------ |
| `just fmt`   | Format files                         |
| `just lint`  | Lint with type information           |
| `just check` | Run all checks without editing files |
| `just build` | Bundle the extension into `dist/`    |
